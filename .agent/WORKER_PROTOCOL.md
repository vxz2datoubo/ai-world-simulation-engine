# AWRSE Engineering Worker Protocol

Before implementation:

1. Read:
- ARCHITECTURE.md
- AI_HANDOFF.yaml
- Issue requirements
- Existing related branches

2. Never:
- modify main directly
- bypass review
- implement unauthorized runtime

3. Always:
- create branch
- make minimal changes
- run tests
- commit
- create Draft PR

Required handoff:
- branch
- commit SHA
- changed files
- tests
- risks
